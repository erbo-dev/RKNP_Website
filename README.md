# MIORA — World-Class Neurotechnology Startup Website

MIORA — Brain–Computer Interface (BCI) сигналдарын бұлшықет кедергілерінен (EMG) қорғайтын 4 деңгейлі каскадты жүйесінің ресми веб-сайты.

## 🚀 Қалай іске қосу керек (Quick Start)

### 1. Тәуелділіктерді орнату (Install Dependencies)
```bash
npm install
```

### 2. Әзірлеу режимі (Development Server)
```bash
npm run dev
```
Браузерде ашыңыз: [http://localhost:3000](http://localhost:3000)

### 3. Өндірістік нұсқаны жинау (Production Build)
```bash
npm run build
npm run start
```

---

## 🌐 Deploy to Vercel (Деплой нұсқаулығы)

Бұл жоба Vercel платформасына 100% бейімделген:
1. [Vercel](https://vercel.com) жүйесіне GitHub арқылы кіріңіз.
2. **Add New...** → **Project** батырмасын басыңыз.
3. `erbo-dev/RKNP_Website` репозиторийін таңдап, **Import** түймесін басыңыз.
4. **Framework Preset:** Next.js (автоматты анықталады).
5. **Deploy** батырмасын басыңыз. Жоба 1 минутта өндіріске шығады!

## 🛠 Технологиялық стек
- **Framework:** Next.js 14 (App Router)
- **UI & Styling:** Tailwind CSS, Lucide React
- **3D Graphics & WebGL:** Three.js, GLTFLoader (Реалистичная 3D анатомическая модель мозга)
- **Typography:** Newsreader (Editorial Serif), Plus Jakarta Sans, JetBrains Mono
- **Language:** TypeScript
